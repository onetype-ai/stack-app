# definePlugin

`definePlugin(name, contract)`. One default export a plugin, and the only
thing `discover` looks for.

The contract is the whole boundary. `Definition` in the reference names every
field and its type; `plugin.ts` in these documents shows the shape.

## Every key

`version`, `describe`, `dependsOn`, `config`, `permissions`, `services`,
`routes`, `pages`, `frame`, `slots`, `contributes`, `emits`, `listens`,
`hooks`, `participates`, `commands`, `sends`, `grants`, `grantsSupported`,
`setup`, `teardown`.

Each is optional but `version` and `describe`. What a key takes is in
`Definition`; what it is for is in the document that covers it.
