# An application, from an empty folder

```
package.json
src/
    main.jsx
    shell.plugin.jsx
    notes.plugin.jsx
    audit.plugin.jsx
```

One dependency, `@onetype/stack-app-kit`, with `react`, `react-dom` and `zod`
beside it, and a router library — `@tanstack/react-router` below.

Each file is its own document:

- `2c1.shell.md` — shell.plugin.jsx — the frame and the status pages
- `2c2.notes.md` — notes.plugin.jsx — a capability
- `2c3.audit.md` — audit.plugin.jsx — reaching into notes
- `2c4.root.md` — main.jsx — the composition root
