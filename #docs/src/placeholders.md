# Placeholders

Substitute every one; none is a name to keep.

| | |
|---|---|
| `<plugin>` | the folder name, lowercase |
| `<Plugin>` | the same, PascalCase, for what it owns |
| `<Type>` | a type the plugin exports |
| `<service>` | its key on `ctx.services` |
| `<member>` | a method or property |
| `<field>` | a field on a type or payload |
| `<other>`, `<Other>` | another plugin, where one is named |
| `<place>` | a slot, named inside the plugin opening it |
| `<item>` | a local holding one parsed or fetched item |
| `<event>` | the name of something that happened, a noun |
| `<action>` | the name of an operation, a verb |
| `<describe>` | one sentence, for whoever reads it |

Methods are verbs in the imperative: `get`, `list`, `create`, `update`,
`remove`, `find`, `send`, `handle`. Never a tense other than that.

Real type names appear as themselves.
