# api/

Every call to the server, one file a surface. It is the only place a path is
written and the only place a response is parsed.

```ts
import { Item } from "../types/Item";

import type { Context } from "@onetype/stack-app-kit";

export const itemsApi = {
    list: async (ctx: Context): Promise<readonly Item[]> =>
    {
        const body = await ctx.http.get("/items");

        return Item.list.parse(body).items;
    },

    create: async (ctx: Context, title: string): Promise<Item> =>
    {
        const body = await ctx.http.post("/items", { body: { title } });

        return Item.schema.parse(body);
    },

    attach: async (ctx: Context, id: string, file: Blob, onProgress: (sent: number, total: number) => void): Promise<void> =>
    {
        await ctx.http.upload(`/items/${encodeURIComponent(id)}/file`, file, { onProgress });
    },
};
```

`ctx.http` carries the call, and `fetch` is a lint error. `upload` sends a
`Blob` or `FormData` with progress, and is never retried. A 4xx or 5xx
throws, and the kit names which. Put `encodeURIComponent` on every id in a
path, since an id carrying a slash would read as another path.
