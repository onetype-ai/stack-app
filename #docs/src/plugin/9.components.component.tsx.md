# components/

One folder a component. It is presentational only: it takes props and
renders them, reaching no service and no other plugin.

```tsx
import styles from "./ItemRow.module.css";

import type { Item } from "../../types/Item";

export type ItemRowProps = {
    item: Item;
    onOpen?: ((id: string) => void) | undefined;
};

export const ItemRow = ({ item, onOpen }: ItemRowProps) =>
{
    return (
        <li className={styles.root}>
            <button type="button" onClick={() => onOpen?.(item.id)}>
                {item.title}
            </button>
        </li>
    );
};
```

It is private to this plugin unless `index.ts` exports it.
