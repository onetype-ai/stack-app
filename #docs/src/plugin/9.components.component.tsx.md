# components/

One folder a component: `<Plugin>Row/<Plugin>Row.tsx` with its own
`module.css`. Presentational only — it takes props and renders them, reaching
no service and no other plugin.

Private to this plugin unless `index.ts` exports it. One a plugin exports is
shown the same way wherever it appears, so a row looks alike on its own page
and inside another plugin's slot.

```tsx
import styles from "./<Plugin>Row.module.css";

import type { <Type> } from "../../types/<Type>";

export type <Plugin>RowProps = {
    <value>: <Type>;
    onOpen?: ((id: string) => void) | undefined;
};

export const <Plugin>Row = ({ <value>, onOpen }: <Plugin>RowProps) =>
{
    return (
        <li className={styles.root}>
            <button type="button" onClick={() => onOpen?.(<value>.id)}>
                {<value>.<field>}
            </button>
        </li>
    );
};
```

Every class comes from the module; a literal colour or spacing value in the
stylesheet is refused by `verify`.
