# plugin.ts

The contract: everything crossing the boundary, named here or absent. The
kernel refuses to start on a contract that does not add up, such as a slot
contributed to that no plugin opens, or a `requires` that no plugin grants.

```ts
import { definePlugin } from "@onetype/stack-app-kit";
import { z } from "zod";

import { ItemsLink } from "./components/ItemsLink/ItemsLink";
import { ItemsPage } from "./pages/ItemsPage/ItemsPage";
import { ItemStore } from "./services/itemStore";

export default definePlugin("items", {
    version: "1.0.0",
    describe: "Lists items, and creates new ones.",

    dependsOn: ["layout"],

    services: (ctx) => ({ items: new ItemStore(ctx) }),

    routes: [
        { path: "/items", title: "Items", component: ItemsPage },
    ],

    contributes: [{ slot: "layout.menu", render: ItemsLink }],

    emits: {
        "items.created": { describe: "An item was created.", schema: z.object({ id: z.uuid() }) },
    },
});
```

Only `version` and `describe` are required. Every other key, and its shape,
is `Definition` in `schemas.md`. `frame` wraps every page but a prerendered
one or one declaring `frame: false`, `pages` replaces the 403 and 404, and
`fallback` renders when a page throws.

A plugin's text goes in `messages`, one object per locale, and is read with
`useLocale("items").text(key)`. A language is added in
`src/kernel/locales.ts` and in every plugin's `messages`.
