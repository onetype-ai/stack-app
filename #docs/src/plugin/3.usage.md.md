~~~md
# items

## Description

Holds items, each with a title, and the page listing them.

## Usage

```ts
const items = await Items.list(ctx);
```

```tsx
<ItemRow item={item} onOpen={open} />
```

## What it declares

- **Routes**: `/items`, every item
- **Slots**: contributes a link to `layout.menu`
- **Events**: `items.created`, with the new id, after a create

## Refusals

- A response that is not a list of items is refused, not rendered.

## Does not

- Decide who may see an item: the server answers only what the viewer may read.
~~~
