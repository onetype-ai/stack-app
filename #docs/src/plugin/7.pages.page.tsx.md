# pages/

One folder a route, named in `routes`. A page reads what it needs through a
hook and composes components and sections. Loading, failure and empty are
states it renders, never ones it hides.

```tsx
import { ItemRow } from "../../components/ItemRow/ItemRow";
import { useItems } from "../../hooks/useItems";
import styles from "./ItemsPage.module.css";

export const ItemsPage = () =>
{
    const { data, isPending, isError } = useItems();

    if (isError)
    {
        return <p role="alert">The items could not be loaded.</p>;
    }

    return (
        <main className={styles.root} aria-busy={isPending}>
            <h1>Items</h1>
            <ul>
                {data?.map((item) => <ItemRow key={item.id} item={item} />)}
            </ul>
        </main>
    );
};
```

The route:

```ts
routes: [{ path: "/items", title: "Items", component: ItemsPage }],
```

A page that throws renders `fallback`. One the viewer may not see renders
`pages.forbidden`. Neither is handled here.

## Prerendered

A route with `render: "prerender"` is written as HTML, with its `head`, by
`pnpm build`, which also writes `sitemap.xml` and `robots.txt` for
`SITE_ORIGIN`. `load` fills the page's cache first through
`ctx.cache.prefetch`. Nothing else is written.

```ts
routes: [{ path: "/", title: "Home", component: Home, render: "prerender",
    head: () => ({ description: "The first page a reader lands on." }) }],
```
