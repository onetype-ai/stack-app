# pages/

One folder a route: `<Plugin>/<Plugin>.tsx` with its own `module.css`. What
`plugin.ts` names in `routes`, and what `frame` and `pages` wrap.

A page reads the address, asks a service for what it needs, and composes
sections. It holds no layout of its own beyond arranging them.

```tsx
import { useParams } from "@tanstack/react-router";

import { <Plugin>Table } from "../../sections/<Plugin>Table/<Plugin>Table";
import styles from "./<Plugin>.module.css";
import { use<Plugin> } from "../../hooks/use<Plugin>";

export const <Plugin> = () =>
{
    const { id } = useParams({ strict: false });
    const { <plugin>s, loading } = use<Plugin>(id);

    return (
        <main className={styles.root}>
            <<Plugin>Table <plugin>s={<plugin>s} loading={loading} />
        </main>
    );
};
```

A page that throws renders what `fallback` names; one the caller may not see
renders `pages.forbidden`. Neither is handled here.
