# Name.module.css

One stylesheet a component, beside it. CSS Modules keep class names local, so
two plugins may both write `.root`.

```css
.root
{
    padding: var(--space) 0;
    border-bottom: var(--hairline) solid var(--edge);
}
```

Every length, colour, radius and duration is a token that the project
declares once in a stylesheet under `src/ui/`, loaded by `main.tsx`:

```css
:root
{
    --space: 12px;
    --hairline: 1px;
    --ink: #1f2937;
    --edge: #e5e7eb;
}
```

A literal outside that sheet, or a token nothing declares, fails `verify`.
State is an attribute rather than a second class: `data-open` or
`aria-busy`, which a test can assert and a screen reader announces.
