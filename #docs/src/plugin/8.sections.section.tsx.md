# sections/

One folder a composed piece: `<Plugin>/<Plugin>.tsx` with its own module.css.
What a page puts together, and what `frame` and `pages` name.

A section may reach this plugin's services and another plugin's public API. It
takes what it renders as props wherever a page already holds it, so the same
section serves two pages.

```tsx
import { <Other> } from "@plugins/<other>";

import { <Plugin>Row } from "../../components/<Plugin>Row/<Plugin>Row";
import styles from "./<Plugin>Table.module.css";

import type { <Type> } from "../../types/<Type>";

export type <Plugin>TableProps = {
    <plugin>s: readonly <Type>[];
    loading?: boolean;
    onOpen?: ((id: string) => void) | undefined;
};

export const <Plugin>Table = ({ <plugin>s, loading, onOpen }: <Plugin>TableProps) =>
{
    if (loading === true)
    {
        return <p className={styles.loading}>Loading…</p>;
    }

    return (
        <ul className={styles.root}>
            {<plugin>s.map((<item>) => (
                <<Plugin>Row key={<item>.id} <item>={<item>} onOpen={onOpen} />
            ))}
        </ul>
    );
};
```

`Slot` renders what other plugins contributed: `<Slot name="<plugin>.<place>"
payload={...} />`, and each contribution declares what it needs.
