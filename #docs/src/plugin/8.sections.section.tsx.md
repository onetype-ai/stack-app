# sections/

One folder a composed piece. A section may reach this plugin's services and
another plugin's public API, and it is what `frame` and `pages` name.

## Opening a slot

`layout` renders `layout.menu` in its frame, and declares it in `slots`:

```tsx
import { Slot } from "@onetype/stack-app-kit/react";

import styles from "./LayoutFrame.module.css";

import type { ReactNode } from "react";

export const LayoutFrame = ({ children }: { children?: ReactNode }) =>
{
    return (
        <div className={styles.root}>
            <nav aria-label="Main">
                <Slot name="layout.menu" />
            </nav>
            {children}
        </div>
    );
};
```

```ts
import { definePlugin } from "@onetype/stack-app-kit";
import { z } from "zod";

import { LayoutFrame } from "./sections/LayoutFrame/LayoutFrame";

export default definePlugin("layout", {
    version: "1.0.0",
    describe: "The frame every page renders inside, with a menu other plugins fill.",

    frame: LayoutFrame,

    slots: {
        "layout.menu": { describe: "A link in the main menu.", schema: z.undefined() },
    },
});
```

## Filling one

`items` names `layout` in `dependsOn` and contributes a component:

```ts
contributes: [{ slot: "layout.menu", render: ItemsLink }],
```

A payload goes through `<Slot name payload>` and is checked against the
slot's `schema`. Neither side imports the other.
