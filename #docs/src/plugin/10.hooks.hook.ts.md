# hooks/

`useName.ts`, one hook a file. A hook covers what a page needs from React
that a service cannot hold: cached data, the address, focus, a timer.

```ts
import { useQuery } from "@tanstack/react-query";

import { Items } from "../index";
import { ItemsKeys } from "../utils/ItemsKeys";

import type { UseQueryResult } from "@tanstack/react-query";
import type { Item } from "../types/Item";

export const useItems = (): UseQueryResult<readonly Item[]> =>
{
    const store = Items.use();

    return useQuery({ queryKey: ItemsKeys.list(), queryFn: () => store.list() });
};
```

The query key comes from `ItemsKeys`, the same key `ItemStore.create` drops,
so the list refetches after a write. A hook that holds the address reads it
with TanStack Router's `useSearch` and parses it with the route's `search`
schema, because a reader may type anything into the address. A hook has no test of
its own: the page using it is the one tested.
