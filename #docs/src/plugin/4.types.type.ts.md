# types/

`Item.ts` holds `Item` as a `type` and a `const` of one name. A value
crossing the boundary carries a schema; a shape only the code uses carries
none.

```ts
import { z } from "zod";

const schema = z.object({
    id: z.uuid(),
    title: z.string().min(1),
});

export type Item = z.infer<typeof schema>;

export const Item = {
    schema,
    list: z.object({ items: z.array(schema) }),
};
```

The schema is a `const` above the object, so the type can be derived before
the object uses it. A config the contract names in `config` is a type here
too, and what `ctx.config` resolves to. A secret never belongs in the
browser.
