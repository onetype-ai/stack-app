# types/

Everything zod parses, and the shapes describing code alone. `<Type>.ts`
holds `<Type>`, as a `const` and a `type` of one name.

A value crossing the boundary carries a schema. A shape the code needs and no
server receives carries none.

```ts
import { z } from "zod";

import { <Other> } from "./<Other>";

export const <Type> = {
    schema: z.object({
        id: z.uuid(),
        <field>: <Other>.schema,
    }),

    <member>: (raw: <Type>): string =>
    {
        return <raw, made regular>;
    },
};

export type <Type> = z.infer<typeof <Type>.schema>;
```

`<Plugin>Config.ts` holds what `plugin.ts` names in `config`, and is what
`ctx.config` resolves to. A secret belongs on the server: nothing here reaches
the browser without shipping in the bundle.
